About

I'm Dasari Ranga Eswar, an AI engineer, data scientist and machine learning researcher. I work on the parts of machine learning that are easy to hand-wave and hard to verify: which optimizer touches which parameter block, whether an ensemble's routing decision was earned, whether synthetic data holds up as data.

Most of my projects start as a question I can't answer by reading. The optimizer work began as a hypothesis about learned routing that turned out to be wrong — so the paper reports the negative result and the one static configuration that did work. traauto grew out of a smaller ensemble library once manual feature prep became the bottleneck. Synthesis came from wanting healthcare-shaped datasets that nobody has to sign a privacy agreement to use.

I build end to end when the problem needs it: PyTorch and TensorFlow training loops, Flask services, React front ends, and geospatial pipelines that turn raw Landsat tiles into something a model can learn from. Two of the libraries below are published on PyPI; the research, the code and the negative results are all public.

Also known or searchable as Ranga, Eswar, or Dasari Eswar — and as @eswaroy on GitHub, @Eshwaroy on X, and eswar199687 on PyPI. Professional history lives on Dasari Ranga Eswar's LinkedIn profile.

Research paper + code

Component–Optimizer Assignment in Transformers

A study of which transformer components should be handed to which optimizer, showing that the assignment is binary and static rather than something worth learning. Extending Muon to the token embedding matrix — excluded by the standard recipe — cuts validation loss by 0.157, while DORoT, a full dynamic routing system built and tested along four axes, never beats its own static control.

traauto

A research-grade AutoML library that turns the Track/Rail ensemble strategy into a full pipeline — automated feature engineering, Optuna-driven meta-learning, and per-record routing to specialised tracks. Ships SHAP and LIME explanations, clustering-based regional models, and checkpoint/resume for long runs.

tra-algorithm

The original Track–Rail ensemble framework that traauto is built on. It routes records between specialised model tracks using real-time signals, then prunes tracks that stop earning their place — adaptive and explainable for both classification and regression.

Synthesis

A GAN-powered platform that generates synthetic electronic health records, time-series vitals and cross-modal healthcare datasets — realistic enough to train on, with no real patient data behind it. React dashboard for configuration and visualisation, Flask and PyTorch service underneath, CSV or JSON out.

Deforestation analysis and prediction

An end-to-end remote sensing pipeline that classifies deforested land in the Amazon from Landsat imagery and tracks vegetation loss over time. Handles TIFF conversion, tiling and augmentation, computes NDVI, then trains an EfficientNetB3 classifier against PRODES ground truth from INPE.
